# Этап 2: Модернизация UI-слоя (Интеграция Vue 3)

Цель: Полный отказ от генерации HTML через строковые шаблоны, внедрение
реактивного управления состояниями, компонентная декомпозиция интерфейса. Стек:
Vue 3 (Composition API), @vitejs/plugin-vue.

## 2.1. Инициализация среды и стратегия монтирования

- Действие: Установка зависимостей Vue и подключение плагина в конфигурацию
  Vite.
- Изоляция DOM (src/utils/vue-mounter.ts): Реализация утилиты для независимого
  монтирования Vue-компонентов. Для каждого приложения (модального окна или
  панели) программно создается скрытый div, который добавляется в конец
  document.body. Метод createApp().mount() вызывается на этих изолированных
  узлах, чтобы избежать конфликтов с DOM-деревом хост-сайта.

## 2.2. Рефакторинг модуля настроек (SettingsModal.vue)

- Действие: Конвертация блока #am-panel (строки 2826–3020) в Single-File
  Component (SFC).
- Реактивность: Замена императивного чтения/записи DOM (через getElementById)
  на двустороннее связывание (v-model). Управление вкладками (Tabs)
  переводится на локальное состояние (ref).
- Синхронизация с хранилищем: Внедрение хука watch(settings, ... , { deep:
  true }) для автоматического сохранения измененных конфигураций в абстракцию
  Storage (или напрямую в GM_setValue до Этапа 3).

## 2.3. Рефакторинг модуля логирования (LoggerModal.vue)

- Действие: Замена функций ручного рендеринга createSingleLogEl и
  renderAllLogs (строки 312–421) на Vue-компонент.
- Декларативный рендеринг: Использование директивы v-for для отрисовки массива
  логов.
- Оптимизация фильтрации: Логика поиска и сортировки по типам (ALL/WARN/ERROR)
  переносится в вычисляемые свойства (computed). Обновление DOM при смене
  фильтра будет происходить автоматически под капотом виртуального DOM (vDOM)
  Vue.

## 2.4. Рефакторинг сканера дельты (Scanner.vue)

- Действие: Декомпозиция логики UI сканера списков (строки 802–965).
- Микрокомпоненты: Выделение независимых сущностей — главного окна
  (ScannerModal.vue) и сворачиваемых списков расхождений
  (ScannerDiffCategory.vue).
- Управление состояниями: Обновление текстовых статусов сканирования и
  управление списками исключений (Ignore-лист) через реактивные переменные
  (Set в реактивной обертке). Устранение необходимости полной перерисовки
  модального окна при скрытии одного элемента.

## 2.5. Рефакторинг панели управления (ActionPanel.vue)

- Действие: Конвертация плавающего блока кнопок (FABs, строки 2806–2819) в
  независимый компонент.
- Коммуникация: Использование системы событий (emit) для информирования
  глобальной шины или родительского контекста о намерениях пользователя
  (например, emit('openSettings')).

## 2.6. Интеграция в точку входа (main.ts)

- Действие: Замена вызовов инициализации старого UI на монтирование
  Vue-приложений.
- Связывание компонентов (Wiring): Настройка взаимодействия между
  изолированными Vue-приложениями. Экспорт внутренних состояний видимости
  модальных окон (через макрос defineExpose({ isVisible })) и привязка их
  изменения к обработчикам событий от ActionPanel.

## 2.7. Универсальный модуль синхронизации (SyncModal.vue)

- Создание единого Vue-компонента, интерфейс которого адаптируется под среду выполнения: на сайте Shikimori (в юзерскрипте) он работает как «Экспорт», а на сайте AniList (в Tauri) — как «Импорт».
- Внедрение в интерфейс явного визуального предупреждения: «⚠️ Ваш профиль на Shikimori должен быть открыт (публичен) на время переноса списков. Если профиль скрыт настройками приватности, сервер откажет в доступе.»

## 2.8. Настройка управления всплывающими окнами Kodik (SettingsModal.vue)

Добавление опции в настройки: «Блокировать всплывающие окна плеера (Popups)» (Чекбокс: [ВКЛ/ВЫКЛ]).

Переключатель дает пользователю право выбора, не лишая Kodik дохода по умолчанию и соблюдая этические договоренности по API-токену.

## 2.9. Менеджер жизненного цикла виджетов (LifecycleManager.ts)

Реализация модуля отслеживания SPA-навигации.

При обнаружении смены роута AniList модуль принудительно вызывает app.unmount() для всех инжектированных ранее Vue-компонентов, предотвращая утечки памяти и фантомное наложение старых виджетов на новые страницы.

Итог Этапа 2: Сокращение объема кодовой базы за счет удаления утилит ручного
управления DOM. Интерфейс становится строго компонентным, предсказуемым и
лишенным уязвимостей XSS. UI-слой теперь полностью отвязан от специфики
юзерскрипта, что является критическим требованием для перехода к десктопной
архитектуре.
