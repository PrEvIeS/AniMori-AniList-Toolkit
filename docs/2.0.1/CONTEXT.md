# Контекст текущего шага

Шаг: номер версии поднят до 2.0.1 — `4905bf2`, `cfa780a`, `f5d18df`,
`8af993d`, `a9e346c`. Этап 6 закрыт целиком, 5.4 заморожен владельцем.

Ручных мест ровно два: `package.json` и `src-tauri/Cargo.toml`. Прежняя
запись в реестре решений «номер только в `package.json`» устарела:
Cargo не умеет читать версию из чужого файла, поэтому второе место
неизбежно.

Остальные потребители номер не хранят: `vite.config.ts` читает его из
`package.json` и подставляет и в шапку юзерскрипта, и в
`__ANIMORI_VERSION__`; `tauri.conf.json` держит ссылку
`"version": "../package.json"`; в `src/core/constants.ts` версии нет.

`Cargo.lock` правит `cargo` при первой же сборке — файл на 150 КБ
через API не записывается, поэтому его коммит делает владелец
локально (`a9e346c`).

В `README.md` заменён только пример имени установщика. Фраза
«Начиная с версии 2.0.0» оставлена: она о появлении двух видов
сборки, а не о текущем релизе.

Попутно убрана порча буквы в комментарии `Cargo.toml`: вместо
подбора символа комментарий переформулирован, чтобы спорной буквы
в нём не было вовсе.

Проверено владельцем: `typecheck` чист, обе сборки зелёные и по
размеру совпадают с прежними, `cargo check` собирает `animori v2.0.1`.

Дальше: правка карт проекта (карточка прокси, темы акцента, кнопка
плеера), сверка кнопок словаря и ссылок на дефект вида, шапка
`ActionPanel.vue` под лимиты стиля. Открыт вопрос о делении
`DECISIONS.md` по версиям.
