Важное ограничение: GitHub читает `.github/ISSUE_TEMPLATE` только из
ветки по умолчанию. До мерджа в `main` вкладка Issues показывает пустой
шаблон, а ссылки из приложения теряют подстановку. Владелец решил
ждать релиза, отдельного коммита в `main` не делаем.

Проверено владельцем: `typecheck` чист, обе сборки зелёные, окно
запускается. После мерджа сверить якорь раздела установки в README
ветки `main`: на него ссылается `config.yml`.
