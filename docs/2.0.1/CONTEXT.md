# Контекст текущего шага

Шаг: этап 6 закрыт целиком — 6.1 (`c5cf7b1`…`a911afc`), вид кнопки
проверки прокси (`dcdd7fd`), 6.2 (`3d78629`…`16a2294`). Следующий — 5.4.

Кнопка плеера. Выбрано одно решение: узел остаётся тем же самым,
а `Teleport` переносит его в колонку `.cover-wrap-inner` — под обложкой,
ниже «Добавить в список», во всю ширину постера.

Второй кнопки нет сознательно: копия потребовала бы второго пути
жизни — своего монтирования, своего снятия и своего обработчика.

Фоллбэк встроен в механику, а не дописан веткой: нет якоря — телепорт
выключен и кнопка рисуется в панели, как до шага. Оттуда же две
подписи: «▶ Смотреть» для крупного места и «▶ Плеер» для панели.

Якорь ищется заново на каждый показ кнопки, потому что AniList при
смене тайтла пересобирает шапку и старый узел уходит из документа.
Зовётся это из `showPlayerButton()`, который `player.ts` вызывает при любой
перерисовке, так что сам `player.ts` править не потребовалось.

Селектор взят из живого DOM, а не из догадок: шапка прислана
владельцем. Атрибуты `data-v-*` в селекторах не используются: их хеши
меняются от сборки к сборке сайта.

Вид крупной кнопки лёг в новый `player-hero.scss`, а не в `style.scss`:
тот за порогом 25 КБ, и его полная перезапись уже теряла содержимое.
Правила заданы парой id и класса — иначе вид кнопок панели перебивал
его по порядку сборки стилей.

Попутно исправлена найденная владельцем белая кнопка «Проверить
сейчас»: базовый `.amk-btn` задаёт только геометрию, без фона и цвета
текста. Отсюда правило: у кнопки всегда есть модификатор вида.
Общий `.amk-btn` намеренно не трогали: правка ради одного места
потребовала бы перезаписи `style.scss`.

Урок партии: содержимое файла через API передаётся обычным текстом.
Первая запись `action-panel-state.ts` ушла в base64 и легла усечённой:
от файла осталась шапка на 464 байта. Содержимое восстановлено
следующим коммитом; в истории остались оба коммита. Потерю поймало
перечитывание файла после записи — правило остаётся в силе.

Проверено владельцем: `typecheck` чист, обе сборки зелёные, `tauri dev`
запускается без жалоб. Кнопка стоит под постером, в панели её больше
нет, появляется стабильно и верстку сайта не ломает.
