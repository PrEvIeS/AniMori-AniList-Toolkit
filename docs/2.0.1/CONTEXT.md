# Контекст текущего шага

Шаг: пункт 6.1 закрыт (`c5cf7b1`…`a911afc`). Следующий — 6.2.
Пункт 5.3.9 закрыт раньше: карточка прокси живёт в «Прочем».

Зачем косметика: реформа вкладок настроек была отклонена владельцем,
вместо перестановки разделов взяты две видимые задачи: темы и место
кнопки плеера.

Темы. `core/accent.ts` держит все варианты в `AM_ACCENTS`: восемь готовых
и «Свой цвет». Цвет хранится триплетом под `am_accent_custom`, а переменная
`--am-accent` осталась единственной точкой влияния на стили.

Тема сайта сознательно оставлена без триплета: она наследует `--color-blue`
AniList и потому следует за оформлением сайта, включая тёмную тему.

Свой цвет вводится двумя способами — пипетка и поле hex. Дубль намеренный:
нативный диалог WebView2 может не открыться, и тогда поле единственный
путь. Кривой ввод игнорируется, слишком светлый цвет даёт подсказку:
белый текст на акцентных кнопках иначе пропадает.

Две ошибки, найденные владельцем после сборки (исправлены `a911afc`):
шаблон рисовал `am-accents`, а раскладка была объявлена у `amk-accents`,
и чипы шли вовсе без зазоров; значок INFO в журнале брал `--am-accent`
и на теме sunset сливался с WARN.

Отсюда два правила. Раскладка чипов — сетка равных колонок, а не flex:
имена тем разной длины давали рваные ряды. Акцент не красит
смысловые категории журнала — только кнопки фильтров и украшения.

Проверено владельцем: `typecheck` чист, обе сборки зелёные,
`tauri dev` запускается без жалоб. Девять чипов встают ровными рядами.
