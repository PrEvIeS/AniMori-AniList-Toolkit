# Переводчик: устройство и грабли

Сюда вынесено «почему» из шапки и длинных док-комментариев
`src/features/translator/index.ts` при чистке по `docs/CODE-STYLE.md`.
Сам файл вырос из строк 2502–3060 монолита.

## Конвейер

1. `MutationObserver` видит новые узлы и переводит интерфейс по словарю.
2. `debouncedFindContent` собирает со страницы ссылки на тайтлы, персонажей и авторов.
3. `queueContent` смотрит в кэш IndexedDB и кладёт в очередь только промахи.
4. `processTransQueue` берёт пачку, спрашивает AniList и Shikimori, кладёт в кэш.
5. `applyTranslation` подставляет русское название в конкретные элементы.

## Отличия от монолита

- Глобальный `window.ensureWidgets` заменён подпиской `registerMutationHook()`.
- `globalPendingQueues` наружу не торчит, вместо него `getPendingQueueSizes()`.
- Флаг `activeRound` висел на самой функции, теперь это переменная модуля.
- Каждый элемент пачки идёт в `try/catch`: одна битая карточка больше не роняет
  всю очередь; в монолите один сбой сети мог её заморозить.
- Перевод никогда не пишется через `textContent` в элемент с разметкой внутри
  (`writeText`): монолит на этом ломал вёрстку карточек и строки виджета франшизы.
- `buildPersonLink`: в монолите домен и фоллбэк подставлялись внутрь шаблонной
  строки и ссылка ломалась — тот же класс багов, что чинил `1306f00`.

## Маркеры на узлах

AniList переиспользует один узел `.tooltip` для разных карточек, а ссылки в списках —
при виртуальном скролле. Поэтому `dataset.translated` и `dataset.queued` хранят id
тайтла, а не флаг `'1'`: иначе узел навсегда глохнет после первого перевода
и покажет оригинал.

Собственный UI обязательно помечать классом `am-notr` (РИСК №4 из `AUDITION.md`):
наблюдатель слушает всю страницу, иначе на Этапе 2 будет цикл Vue ↔ переводчик.

## Темп запросов (пункт 3.8)

Раньше после каждого элемента пачки стояла своя пауза (250 мс для тайтлов,
300 мс для персон) поверх шлюза внутри api-клиентов. Двойной троттлинг:
пачка из сорока тайтлов простаивала десять секунд даже когда все сорок брались
из кэша. Теперь темп держит общий ограничитель (`src/api/rate-limit.ts`),
а очередь отдаёт работу так быстро, как её берут: `acquireSlot()` притормозит сам.

Там же в проверку лимитов добавлен anime365: он стоит в той же цепочке резолва
названий, что и Shikimori, и если он в паузе или бэкоффе, новая пачка бессмысленна.

## Разобранные дефекты

Подробный разбор — в журнале ч.3 §6.9–6.11 и аудите от 31.07.

| Дефект | Суть | Как закрыт |
| --- | --- | --- |
| Потеря элементов (аудит 31.07) | id удалялся из `pending` ДО запроса; сбой сети или молчание AniList оставляли карточку английской до перезагрузки | Любой неуспех возвращает id и снимает маркер; после `MAX_ATTEMPTS` ключ отпускается |
| A6 | Маркер `dataset.queued` ставился до `await dbGet`; отказ IndexedDB никто не ловил (вызов через `void`) | Маркер ставится после учёта элемента, любой сбой его снимает |
| A7 | Промахи во время работы цикла терялись: `processTransQueue` выходила по `isProcessing`, а работающий цикл уже проверил `totalPending()` | Флаг `rerunRequested` и ещё один круг через `scheduleDispatch()` |
| A8 | После `MAX_ATTEMPTS` запись в `attempts` оставалась: новый узел получал `tries = 4` и отбрасывался без попыток | `resetTranslatorRetries()` на смену роута |
| A11 | Строгий приоритет MED2 морил голодом CHR2/STF3; после ухода со списка в очереди висели сотни карточек покинутой страницы | Персоны идут первыми (пачка вчетверо меньше); `dropDetachedEntries()` чистит оторванные узлы |
| A12 | Отбор шёл в порядке обхода DOM: при потолке 60 запросов в минуту пролиставший вниз ждал все карточки выше | `pickBatch()` сортирует по `entryDistance()`, видимое первым |

## Мелкие грабли

- `DISPATCH_DELAY_MS` — окно фиксированное, а не скользящее: непрерывный поток промахов
  при скролле иначе откладывал бы старт бесконечно.
- Нулевая рамка в `entryDistance()` — узел в документе, но не отрисован (скрытая
  вкладка, свёрнутый блок): показывать перевод некому.
- При 429 от Shikimori в очередь возвращается весь остаток пачки: id уже вынуты
  из `pending` и без возврата теряются безвозвратно.
- Тултип: ориентируемся не на маркер «уже переводили», а на совпадение видимого
  текста с `dataset.ru`; адресат определяется через `:hover` и `dataset.translatingId`.
- Оригинальное описание в раскрывашке помечено `am-notr`, иначе переводчик со
  временем перепишет его фразы и кнопка теряет смысл.
- Плитки-обложки (избранное на профиле) текста не держат: имя показывает родной
  тултип AniList, писать в такую ссылку нечего.
