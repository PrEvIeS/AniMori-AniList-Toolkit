# Реестр решений

Строка на решение: дата · предмет · причина · хеш. Формат — `docs/DOC-RULES.md`.
Развёрнутое «почему» — в теле коммита: `git show <хеш>`. Прочерк вместо хеша
значит, что коммит не восстановлен при переносе из старых журналов.

## Архитектура

- 2.0.0 · Одна кодовая база, два продукта · ветвление решается алиасами сборки, иначе `@tauri-apps/*` уедут в браузерный бандл · —
- 2.0.0 · Мост платформы вместо прямых `GM_*` · десктопу нужны асинхронные хранилище и HTTP через Rust · —
- 2.0.0 · Окно десктопа открывается на живом anilist.co · приложение — браузер одного сайта, локального фронта нет · —
- 2.0.0 · Окно создаётся кодом в `setup()`, а не в конфиге · нужны внешний адрес и скрипты инициализации · —
- 2.0.0 · Внешние ссылки уходят в системный браузер · иначе окно без адресной строки уезжает на чужой сайт · —
- 2.0.0 · Минификация выключена, динамический `import()` запрещён · правила Greasy Fork и отсутствие чанков в юзерскрипте · —
- 2.0.0 · Номер версии только в `package.json` · три места расходились и сломали тег релиза · —
- 2.0.0 · Списки рекламы собраны вручную, без EasyList · полноценный движок фильтров отложен в 2.0.1 · —
- 2.0.0 · Блокировщик живёт в оболочке, а не в странице · реклама плеера грузится во вложенных кадрах · —
- 2.0.0 · Адблока нет в юзерскрипте вовсе · разведчик без проверки платформы уехал в браузерную сборку · —
- 2.0.0 · Обновления ведёт Rust, а не фронтенд · расхождение с планом, так проще с подписью и тихой установкой · —

## Старт и жизненный цикл

- 2.0.0 · Всё, что читает настройки, идёт после `loadSettings()` · хранилище Tauri асинхронное, до ответа в объекте дефолты · —
- 2.0.0 · Каждый шаг старта обёрнут в `step()` · падение одного не должно обрывать остальные · —
- 2.0.0 · Гейт `whenDomReady()` ждёт и событием, и опросом · скрипт выполняется до DOM, между проверкой и подпиской есть зазор · —
- 2.0.0 · Задачи смены роута идемпотентны · повторный прогон — штатный способ дожать невышедшее · —
- 2.0.0 · Три источника событий навигации плюс пулинг 800 мс · SPA на React не перезагружает документ · —
- 2.0.0 · Уборка фантомных корней `am-vue-root` · React переносит разметку вместе с нашим корнем · —
- 2.0.0 · Переводчик запускается всегда, даже при выключенном переводе · на его наблюдателе живут медиа-виджеты · —
- 2.0.0 · Адблок идёт до первой отрисовки · иначе баннер успевает мигнуть · —
- 2.0.0 · Кольцевой буфер журнала вместо бесконечного массива · десктоп работает сутками, цикла вкладки нет · —

## Живые ограничения (прежние РИСКИ из аудита)

- РИСК №1 · Настройки пишутся только через `saveSetting()` · прямой `GM_setValue` ломает асинхронное хранилище десктопа · —
- РИСК №2 · Приватный API Shikimori из Rust уходит анонимным · cookies WebView недоступны HTTP-клиенту оболочки · —
- РИСК №3 · Имена `.amk-*` и `#am-panel` менять нельзя · на них завязан живой UI и селекторы монолита · —
- РИСК №4 · Корни Vue исключены из наблюдателя переводчика · иначе реактивные микро-мутации дают лавину · —
- РИСК №5 · На Linux плеер может не иметь кодеков H.264 · WebKitGTK без GStreamer даёт чёрный экран, важно для порта · —
