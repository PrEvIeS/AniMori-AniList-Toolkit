# capabilities

## Purpose

ACL окна `main`. Для окна, открытого на **внешнем** URL, Tauri работает иначе, чем для локального фронтенда: вызвать можно ровно то, что здесь перечислено, и собственные команды приложения тоже требуют разрешения.

## Key Files

| File | Description |
|------|-------------|
| `default.json` | Единственная capability: `windows: ["main"]`, `remote.urls` = `https://anilist.co` и `https://*.anilist.co`, список разрешений и белый список адресов для `http:default` |

## For AI Agents

### Working In This Directory

- **Каждое разрешение здесь получает любой скрипт `anilist.co`.** Это главный критерий при добавлении: «а если это вызовет чужой код на странице?». Именно поэтому `updater` и `dialog` разрешений не имеют — их дёргает только Rust.
- **Собственные команды называются `allow-<имя-в-kebab-case>`:** `animori_reload` → `allow-animori-reload`. Имена порождает `AppManifest::commands` в `build.rs`; без объявления там разрешения не существует, и вызов падает с «not allowed. Plugin not found».
- **Белый список `http:default` обязан совпадать по смыслу с `@connect`** в шапке юзерскрипта (`vite.config.ts`). Новый хост в `src/api/` без записи здесь молча не работает в десктопе.
- **Три последних адреса списка** (`s4.anilist.co`, `kodikplayer.com`, `github.com/foulnike/…`) нужны только вкладке «Разработчик» для проверки доступности: раздача обложек, домен плеера и файл обновления в обычной работе идут не через мост, а через страницу, iframe и механизм обновлений.
- **`$schema` указывает в `../gen/schemas/`** — каталог генерируемый и в `.gitignore`; отсутствующая схема на сборку не влияет.
- **Файл с табами**, в отличие от остального JSON проекта; `.prettierignore` это учитывает — не переформатируй бездумно.

### Testing Requirements

Проверяется только сборкой и живым запуском: отсутствующее разрешение даёт не ошибку компиляции, а отказ в рантайме с сообщением в консоли WebView.
