# api

## Purpose

Клиенты внешних источников данных. Здесь живёт **стратегия обращения к сети**: перебор зеркал, ограничение темпа, повторы, бэкофф, отключение источника на сессию и прикладная трактовка HTTP-кодов. Транспорт при этом свой не заводится — все запросы уходят через `Bridge.http`.

| File | Description |

## For AI Agents

### Working In This Directory

- **Ограничитель — один на источник, а не на домен.** Лимит считается по IP, зеркала делят общий бюджет.
- **Каждый клиент обязан докладывать в `core/net-health.ts`** через `reportStatus()` / `reportError()` со своими константами `NET_SOURCE_*` и `NET_LABEL_*`. Эти же идентификаторы литералами продублированы в `features/ui/net-check.ts` — при переименовании правь оба места.
- **Трактовка кодов — здесь, не в мосте.** «403 у anime365 — блокировка, а не пустота», «404 у списков — конец страниц» — это прикладное знание.
- **Не добавляй новый хост, не добавив его** в `@connect` шапки юзерскрипта (`vite.config.ts`) и в `http:default` десктопных разрешений (`src-tauri/capabilities/default.json`). Пропуск любого из двух даёт молчаливый отказ ровно в одной из сборок.
- **Настройки читаются внутри функций** (`titles.ts`), не на верхнем уровне модуля.

### Testing Requirements

Автотестов нет. Проверка руками через вкладку «Разработчик» в панели настроек: кнопка ручного прогона (`features/ui/net-check.ts`) обходит все адреса и печатает статус и задержку по каждому. Логи запросов видны во встроенном логгере по фильтру `API`.

### Common Patterns

- Возврат `null` вместо исключения там, где отсутствие данных — штатный исход; исключения оставлены для отказов, которые обязан увидеть вызывающий (`RateLimitError`, `BridgeHttpError`).
- Пауза по 429 живёт в клиенте, а не в очереди: только клиент видит все свои запросы разом.
- Таймаут одного зеркала — 5 секунд: дольше ждать бессмысленно, лучше уйти на следующее. Исключение — списки профиля (20 с).

- `../core/net-health` — учёт доступности
- `../core/db` — кэш ответов (`animethemes`, `dictionary`)
- `../utils/logger`, `../utils/name-match`

### External

Прямых сетевых зависимостей нет: всё через мост.
