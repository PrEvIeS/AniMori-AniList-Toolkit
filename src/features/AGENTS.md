# features

## Purpose

Контейнер прикладных модулей. Каждый подкаталог — самостоятельная функция AniMori со своей точкой входа `init*()`, которую вызывает `src/main.ts`. Общего кода на этом уровне нет: собственных файлов в каталоге нет вовсе.

## Subdirectories

| Directory | Purpose |
|-----------|---------|
| `translator/` | Перевод интерфейса, названий, персонажей и персонала: очередь, кэш, наблюдатель DOM (см. `translator/AGENTS.md`) |
| `media/` | Каркас страницы тайтла и пять виджетов сайдбара: плеер, рейтинги, франшиза, темы, внешние ссылки (см. `media/AGENTS.md`) |

## For AI Agents

### Working In This Directory

- **Фичи не импортируют друг друга напрямую, кроме оговорённых точек.** Фактические межфичевые связи: все модули с кнопками идут в `ui/action-panel-state.ts`; `media/` подписывается на `translator/registerMutationHook()`; `media/player.ts` дёргает `ui/action-panel-state` для кнопки плеера. Новых связей без нужды не заводи.
- **Типовой раскрой модуля:** `index.ts` (точка монтирования и регистрация кнопки) + `*-state.ts` (реактивное состояние) + `*.vue` (только разметка) + отдельный файл с логикой (`compare.ts`, `sync-api.ts`, `rules.ts`). Разделение не косметическое: `index.ts` монтирует SFC, SFC читает состояние — прямой импорт состояния в `index.ts` замкнул бы граф.
- **Каждая фича обязана уметь не запуститься.** `main.ts` оборачивает каждый `init*()` в `step()`, но и внутри проверяй свои предусловия: сломавшаяся модалка не должна лишать пользователя панели действий.
- **Своя разметка помечается `am-notr`.** Иначе переводчик пойдёт переводить собственный UI AniMori и зациклится.

### Testing Requirements

Ручной прогон на живом `anilist.co`. У большинства фич есть тумблер в панели настроек — проверяй оба положения, включая выключение на лету.

### Common Patterns

- Регистрация кнопки: `registerActionButton({ id, order: ACTION_ORDER.x, ... })`; порядок пилюль задаёт `ACTION_ORDER`, а не порядок вызовов.
- Видимость кнопки завязана на `computed` из `ui/settings-state.ts` (`showCompareButton`, `showSyncButton`, …).
- Тяжёлые структуры (снапшоты на десятки тысяч записей) держатся в `shallowRef`: глубокая реактивность там вредит.
