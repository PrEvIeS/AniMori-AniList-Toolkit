# adblock

## Purpose

Блокировщик рекламы **десктопной сборки** и инструмент сопровождения к нему. В браузерную сборку не попадает вовсе: там рекламу режет расширение пользователя, и делает это лучше — расширение видит кадр плеера, куда наш код заглянуть не вправе.

Работа поделена надвое, но для пользователя это один тумблер «Блокировщик рекламы»:

| Половина | Где | Что делает |
|---|---|---|
| Разметка | этот каталог (`index.ts`) | Прячет баннеры самого AniList стилями — главный фрейм, наш домен |
| Сеть, Windows | `src-tauri/src/adblock.rs` | Отбивает запросы через `WebResourceRequested` WebView2, включая рекламу **внутри** кадра плеера (`kodikplayer.com`) |
| Сеть, macOS | `src-tauri/src/adblock_macos.rs` | То же самое через `WKContentRuleList`: правила действуют во всех фреймах, кадр плеера накрыт так же |

## Key Files

| File | Description |
|------|-------------|
| `index.ts` | Скрытие баннеров AniList: строка стилей (`ADBLOCK_STYLE_ID`), наблюдатель мутаций, счётчик. `initAdblock()`, `destroyAdblock()`, `syncAdblock()`, `getBlockedCount()` |
| `net-block.ts` | Связь страницы с блокировщиком в Rust: приём докладов о заблокированных доменах и переключение тумблером |
| `net-probe.ts` | Разведка: кто и куда ходит внутри кадра плеера. Горячие клавиши, отчёт в буфер обмена (`copyNetProbeReport`) |
| `impl.desktop.ts` | Цель псевдопути `@adblock-impl` для десктопа: реэкспорт реальных функций |
| `impl.noop.ts` | Цель `@adblock-impl` для юзерскрипта: заглушки с теми же сигнатурами |

## For AI Agents

### Working In This Directory

- **Реализацию выбирает `resolve.alias` по `mode`, а не проверка платформы.** `initAdblock()` тянет наблюдатель мутаций, строку стилей и `net-block.ts` — Rollup вправе сохранить эти побочные эффекты даже после удаления недостижимой ветки `if`.
- **Заглушки, а не удалённые вызовы.** Ни `main.ts`, ни панель настроек не должны знать о платформе. Сигнатуры `impl.noop.ts` совпадают с `impl.desktop.ts`, поэтому расхождение станет ошибкой сборки. `tsconfig.json` целит `@adblock-impl` в `impl.desktop` (у него полные сигнатуры), но обе цели входят в `include` и проверяются отдельно.
- **Каналов переключения два.** На macOS у WKWebView перехвата https-запросов нет вовсе, поэтому там именованный обработчик сообщений `animoriAdblock` (имя продублировано в `net-block.ts` и `adblock_macos.rs` — разойтись не должны). Ниже описан путь Windows.
- **Доклад о заблокированных доменах работает только на Windows.** `WKContentRuleList` декларативный, колбэка на срабатывание нет — на macOS блокировка есть, а счётчика в журнале нет.
- **Переключение идёт не через `invoke`.** Вызов команды потребовал бы выдать новое разрешение контексту `anilist.co`, то есть **любому** скрипту чужого сайта. Вместо этого страница дёргает адрес на несуществующем домене `https://adblock.animori.invalid`, а блокировщик видит этот запрос и переключается. Зона `.invalid` зарезервирована стандартом и никогда не разрешается в сети: без блокировщика запрос просто тихо умирает.
- **`net-probe.ts` — инструмент сопровождения, а не функция продукта.** Список рекламных адресов в `adblock.rs` — снимок на дату, а рекламные сетки меняют домены. Без разведчика обновлять этот список нечем. Живёт в проекте насовсем, парой с `NET_PROBE_SCRIPT` из `src-tauri/src/lib.rs`.
- **Разведка заглушена в браузере намеренно:** улов там применять нечем, а горячие клавиши отбирали бы у браузера `Ctrl+Shift+S` и `Ctrl+Shift+A` прямо на `anilist.co`.
- **Адблок инициализируется раньше любого UI** (`bootstrap()`), иначе баннер мигнёт. В задачи смены роута он **не** входит: его наблюдатель обязан переживать переходы.
- **Слои разметки баннера сняты с живого сайта** и перечислены в шапке `index.ts`. Сайт их меняет — сверяйся с реальной страницей, а не с комментарием.

### Testing Requirements

Только десктоп и только Windows. Включить тумблер, открыть страницу с баннерами и запустить плеер; заблокированные домены видны в логгере. Для обновления списка адресов: запустить разведку горячей клавишей, походить по плееру, снять отчёт `copyNetProbeReport()` и перенести адреса в `src-tauri/src/adblock.rs`. По умолчанию блокировщик **выключен** и включается вручную.
