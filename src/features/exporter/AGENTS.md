# exporter

## Purpose

Перенос списков и избранного Shikimori → AniList: аниме, манга, избранное (аниме, манга, персонажи, персонал) и точные даты просмотров из истории. **Единственный модуль проекта, который пишет данные в чужой аккаунт** — требует токена AniList.

## Key Files

| File | Description |
|------|-------------|
| `sync-api.ts` | Сеть и сравнение записей без DOM (647 строк): чтение списков и избранного Shikimori, история дат, чтение текущего состояния AniList, маппинг статусов и оценок, сами мутации (`syncShikiToAlList`, `syncShikiToAlFavorites`) |
| `sync-state.ts` | Реактивное состояние окна: поля ввода, тумблеры (`optAnime`, `optManga`, `optFavs`, `optDates`), прогресс, генерация ссылки OAuth, `runSync()` |
| `index.ts` | Точка монтирования и регистрация кнопки переноса |
| `SyncModal.vue` | Разметка окна переноса |

## For AI Agents

### Working In This Directory

- **Направление одно: Shikimori → AniList.** `SyncMode` объявлен как union, но `syncMode` — константа `'import'`. Обратного переноса нет.
- **Токен не хранится здесь.** Его кэш живёт в `api/anilist.ts`, отсюда только геттер и сеттер. Для переноса это критично: токен сохраняется прямо перед серией авторизованных запросов, и запись только в асинхронное хранилище означала бы, что первый же запрос уйдёт без токена и весь экспорт упадёт на первом шаге.
- **Вход один — пилюля в панели действий AniList.** Точки на Shikimori больше нет: десктопная оболочка показывает только `anilist.co`, вход на чужом домене там недостижим, а два сценария пришлось бы тестировать отдельно.
- **Оценки конвертируются под формат аккаунта.** `convertScoreShikiToAL()` учитывает `POINT_100` / `POINT_10_DECIMAL` / `POINT_10` / `POINT_5` / `POINT_3` — формат читается из профиля AniList, не угадывается.
- **Даты сравниваются через `fuzzyEquals()`**, а не `===`: AniList хранит `FuzzyDate` с необязательными полями.
- **В оболочке запрос к Shikimori анонимен** (без куки): закрытый профиль не выгрузится, и это отдельная ветка с понятным сообщением (`hiddenProfileMessage()`), а не общий отказ.
- **Прогресс уходит наружу через `onProgress`,** сеть не знает о разметке. Счётчик отказов доступен через `getSyncFailures()` / `resetSyncFailures()`.

### Testing Requirements

Нужен токен AniList и аккаунт Shikimori. **Прогон необратим — он меняет реальный список.** Тестируй на пустом или тестовом аккаунте AniList. Сценарии: перенос без токена (внятный отказ), закрытый профиль Shikimori, каждый тумблер по отдельности, повторный прогон поверх уже перенесённого (не должно быть дублей).

### Common Patterns

- `mapStatusShikiToAL` — единственная таблица соответствия статусов; `reading`/`rereading` у манги маппятся отдельно от `watching`.
- Пилюля кнопки показывает прогресс через `pillProgress` — вычисляемую строку из `sync-state.ts`.
- Идентификаторы AniList берутся по MAL ID пачкой (`getAnilistIds`), поштучный поиск по имени (`getAnilistIdByName`) — только фоллбэк.
