# scanner

## Purpose

Сверка списков Shikimori ⇄ AniList: сводная статистика, поимённые расхождения по статусу, оценке, прогрессу, пересмотрам и заметкам, сравнение избранного (аниме, манга, персонажи, персонал), детект связанных сезонов и игнор-лист. Читает оба списка, ничего не меняет — правки списков делает `exporter/`.

## For AI Agents

### Working In This Directory

- **`compare.ts` отдельно от `index.ts` из-за цикла импортов:** `index.ts` монтирует `ScannerModal.vue`, компонент читает `scanner-state.ts`, а состоянию нужны функции сверки.
- **Реактивная цепочка намеренно разведена на две части:** тяжёлая (`snapshot` → `diffA`/`diffM`/`stats`/`fav*`, пересчёт только после скана) и дешёвая (`diff*` + `ignore` → секции, фильтрация массивов). Иначе каждый клик по ✕ в игнор-листе пересчитывал бы всё сравнение целиком.
- **Снапшот лежит в `shallowRef`:** внутри `Map` на десятки тысяч записей, глубокая реактивность там вредит.
- **Потолок строк в секции и хвост «…ещё N» обязательны.** Без них секция на десятки тысяч строк кладёт рендер.
- **Отмена мягкая:** флаг `CancelToken` проверяется на границах шагов и между чанками глубокой проверки. Сами сетевые запросы не прерываются — процесс встаёт на ближайшей границе. Это осознанный компромисс, не дефект.
- **Статусы нормализуются к терминам Shikimori** (`ShikiStatus` из `core/types.ts`); записи AniList приводятся к ним, а не наоборот.
- **Класс `.amk-overlay` объявлен с `display: none`** — на корне модалки стоит инлайновый `style="display: flex"`. Не убирать (см. `../ui/AGENTS.md`).

### Testing Requirements

Нужен реальный аккаунт Shikimori с непустым списком и токен AniList (для `fetchViewerName()` и приватных данных). Обязательные сценарии: скан без токена, скан закрытого профиля Shikimori, отмена на середине, добавление и снятие записи в игнор-листе, список на несколько тысяч записей (проверка потолка секций).

### Common Patterns

- `CMP_STATUS_ORDER` и `CMP_STATUS_LABEL` задают порядок и подписи статусов в UI — менять только парой.
- Игнор-лист хранится знаковыми id (`addIgnore(id, ±1)`): знак различает аниме и мангу.
- Логин Shikimori сохраняется между сеансами (`saveShikiLogin`), имя AniList подставляется автоматически по токену.
