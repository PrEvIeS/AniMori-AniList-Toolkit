# ui

## Purpose

Общий интерфейс тулкита: плавающая панель действий в левом нижнем углу, панель настроек со вкладками, модалка журнала, тост о недоступности источников, перехват ссылок и блок навигации десктопной сборки. Самый населённый каталог проекта (23 файла).

## For AI Agents

### Working In This Directory

- **Пара «точка входа + `*-state.ts`» обязательна.** `actions.ts` монтирует `ActionPanel.vue`, а компонент читает реестр кнопок — держать реестр в `actions.ts` значит замкнуть граф. Та же схема у настроек, журнала и навигации.
- **Запись настроек только через `saveSetting()`** из `core/settings`. Прямая мутация `settings.x` не попадёт на диск.
- **Стили не scoped, живут в `src/style.scss`.** Идентификаторы `am-panel`, `set_*`, `am-dict-*`, `am-custom-*`, `am-sup-*`, `amk-*` и имена классов сохраняются намеренно — переименование в SFC тихо ломает вид.
- **Грабли `.amk-overlay`:** в `style.scss` он объявлен с `display: none`, показ раньше выставлялся императивно. При `v-if` это приходится задавать явно, поэтому на корне `ScannerModal.vue` стоит инлайновый `style="display: flex"`. Не убирать до перевода `amk-*` в scoped.
- **Поля ввода идут через `:value` + `@change`, а не `v-model`,** там где значение нормализуется (домены, строки словаря): иначе запись шла бы посимвольно и `normalizeDomain` резал бы адрес на лету.
- **Идентификаторы источников в `net-check.ts` заданы литералами** и обязаны совпадать с константами `NET_SOURCE_*` в `src/api/*`. Тайпчек это расхождение не поймает.
- **`nav.ts`, `links.ts`, `reload.ts`, `SettingsProxyCard.vue` — десктопная половина.** В юзерскрипте они либо не монтируются, либо опираются на заглушки моста. Ветвлений по платформе в `actions.ts` быть не должно — ради этого навигация и вынесена отдельно.
- **Тост монтируется не постранично:** снятие на смене роута сбросило бы отметку «уже показано».

### Testing Requirements

Проверять в обеих сборках. Для юзерскрипта: панель ⚙ появляется внизу слева, все вкладки открываются, настройки переживают перезагрузку. Для десктопа дополнительно: блок навигации, `Alt+←`/`Alt+→`, F5, F11, внешняя ссылка уходит в системный браузер, карточка прокси видна.

### Common Patterns

- Кнопка регистрируется через `registerActionButton({ id, order: ACTION_ORDER.x, onClick })`; видимость — `computed` из `settings-state.ts`.
- Тяжёлые списки (журнал, диффы) держатся в `shallowRef` и режутся потолком: в DOM записей накапливалось до шести тысяч.
- Внешние ссылки открываются через `window.open`: в десктопе их перехватывает оболочка и отдаёт браузеру.
