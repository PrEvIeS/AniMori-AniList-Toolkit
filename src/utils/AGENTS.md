# utils

## Purpose

Платформонезависимые вспомогательные модули нижнего слоя. Ни один из них не знает о фичах и не обращается к сети напрямую; переезжают между сборками без правок.

## Key Files

| File | Description |
|------|-------------|
| `logger.ts` | Ядро журнала: `Logger()`, типы записей (`INFO`/`WARN`/`ERROR`/`DB`/`API`/`QUEUE`), кольцевой буфер на `LOG_CAPACITY = 500`, `registerLogSink()`, `installGlobalErrorHandlers()`, `safeCall()` |
| `vue-mounter.ts` | Единая точка монтирования Vue: `mountApp()`, `unmountApp()`, `unmountPageScoped()`, `sweepPhantomRoots()`, `unmountAll()`, `getExposed()`. Класс корня — `am-vue-root` |
| `dom.ts` | `escapeHTML()`, тег-шаблон `html\`\`` с автоэкранированием, `rawHTML()`, `applyMarquee()`, `amCopy()`, `getPlural()` |
| `name-match.ts` | Скоринговый матчер имён без сети: `scoreNameMatch()`, нормализация ромадзи и кандзи, сжатие долгих гласных, токенизация |

## For AI Agents

### Working In This Directory

- **`createApp().mount()` вне `vue-mounter.ts` запрещён.** Две причины: (1) корень обязан получить класс `am-notr` **до** первого `mount()`, иначе наблюдатель переводчика зайдёт в свежую разметку, Vue вернёт свой текст, и цикл мутаций не закончится; (2) AniList на React без предупреждения сносит чужие узлы — вырезанный контейнер оставляет живой экземпляр с подписками (zombie-компонент и утечка). Порядок буквально: класс → вставка в DOM → `mount()`.
- **Шкалу баллов в `name-match.ts` нельзя менять без проверки на живых данных.** 100 — точное совпадение кандзи, 90 — кандзи подстрокой, 85 — тот же набор токенов ромадзи, 80 — совпадение после сжатия гласных, 55 — почти полное пересечение, 30 — общая длинная подстрока. Пороги потребителей: 80 для поиска по всему каталогу, 55 для поиска среди ролей конкретного тайтла.
- **Вытеснение в буфере логгера не слепое:** `ERROR` держится, пока в буфере есть что-то ещё. Иначе ошибки терялись бы ровно при обвале, который сам же заливает журнал записями `API` и `QUEUE`. `LOG_CAPACITY` согласован с `MAX_UI_LOGS` в `features/ui/logger-state.ts`.
- **`settings.enableLogger` не спрашивается на верхнем уровне модуля:** импорты выполняются до `bootstrap()`, там всегда дефолт `true`.
- **Аккуратно с `html\`\``:** все интерполяции экранируются. Доверенный HTML надо явно оборачивать в `rawHTML()`, а шаблонная строка **без** тега `html` не экранирует ничего.

### Testing Requirements

`npm run typecheck`. Правки `vue-mounter.ts` проверяются переходами между страницами AniList: смонтированных приложений после `unmountPageScoped()` не должно оставаться, фантомных `am-vue-root` в DOM — тоже (`listMountedApps()` и `sweepPhantomRoots()` в помощь).

### Common Patterns

- UI сюда не входит: связь с модалкой журнала — через подписку `registerLogSink()`, а не через импорт компонента.
- Запись логов в `sessionStorage` пакетная: синхронный `JSON.stringify` на каждую запись тормозил то, что логирует.
